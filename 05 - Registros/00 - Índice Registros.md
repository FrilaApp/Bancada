# 📋 Índice — Registros

Log de **fatos**: o que aconteceu, de forma verificável. Escrito automaticamente pelos hooks do Git e do Claude Code, uma linha por evento.

> [!warning] Não editar à mão
> Este é o material bruto de onde sai o diário. Editar aqui quebra a rastreabilidade — a narrativa vive em [[02 - Atualizações Diárias/00 - Índice Diário|Atualizações Diárias]].

Cada linha tem a forma:

```
- `hora` · **autor** · `tipo` · descrição
```

Tipos de fato: `commit` · `pages` · `sessao`
