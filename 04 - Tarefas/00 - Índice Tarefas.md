# ✅ Índice — Tarefas

O quadro vive em [[04 - Tarefas/Quadro.base|Quadro]]: uma nota por tarefa, agrupada por `status`.

## Como funciona

Cada tarefa é uma nota própria, não um cartão dentro de um arquivo compartilhado. É o que permite cinco pessoas mexerem no quadro ao mesmo tempo sem conflito de merge — duas pessoas editando tarefas diferentes editam arquivos diferentes.

Mover uma tarefa de coluna = mudar a propriedade `status` da nota.

| Status | Significa |
|---|---|
| `a-fazer` | Definida, ninguém começou |
| `em-andamento` | Alguém está tocando agora |
| `revisao` | Feita, esperando olhar de outra pessoa |
| `concluida` | Fechada |

Para criar uma tarefa, use `/tarefa` no Claude Code — ele cuida do id sequencial e do frontmatter.
